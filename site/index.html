Public POC: all saved details and their history are public. "Deployed by" is entered manually, not verified. Saving records a deployment; it does not deploy an application.

Enable saving with a GitHub token

Create a short-lived fine-grained token restricted to environment-deployment-tracker, with Contents: Read and write. Your GitHub account must have repository write access.

The token is sent only to api.github.com, kept in memory, and cleared on reload. Never paste it into a deployment field. Use Clear token when finished.
